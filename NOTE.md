## Linux shell
- https://swcarpentry.github.io/shell-novice/
- `COMMAND --help`
- `ls [OPTION] [PATTERN]`
  - `-F`: showing /
  - `-a`: showing ../
  - `-r`: reverse
  - `-R`: recursive
  - [PATTERN]: \*.ext, ? (any single character)
- `pwd`
- `cd`
  - w/o options: going back to home ~
  - `..`
- TAB completion
- `mkdir`
  - `-p`: for multi-level folders
- `nano` (text editor)
  - Ctrl-o + Enter: save
  - Ctrl-x: exit
- `mv SRC/ DEST/`
- `cp FILE_A FILE_B`
- `rm`
  - `-i`: interactive mode
  - `-r`: for folders
- `wc` (word counts)
  - `-l`: lines
- `>`: print into
- `sort`
  - `-n`: numeric
  - `-r`: reverse
- `head`/`tail`
  - `-n #`: # of lines
- `|` (pipe)
- `uniq`
  - `-c`: unique counts of sequential lines
- `cut`
  - `-d ,`: delimiter
  - `-f #`: field #
- Shell scripts (.sh)
  - `bash script.sh`
  - `#`: comments
  - `"$#"`: shorthand for argument #
